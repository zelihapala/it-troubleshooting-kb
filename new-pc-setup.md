## Summary
This checklist makes sure a PC is prepared the same way every time for a new employee.

## Symptoms
Not a fault. A new PC needs to be prepared.

## Cause
Not applicable. This is a routine task.

## Resolution
1. Turn on the computer and complete the first Windows setup.
2. Open Settings > Windows Update and install all updates. Restart and check again until no updates remain.
3. Open Settings > Privacy & security > Windows Security and check that virus and threat protection is on and up to date.
4. Install the programs the employee's department needs.
5. Create the employee's user account. Give a temporary password and force a change at first sign-in.
6. Write the computer's serial number and who it was given to in the asset list.
7. Test that the internet, the printer and email work.

## Verification
All items are ticked and the employee can sign in with their account.

## Prevention
Use the same checklist for every PC so that no step is missed.

## Escalation
Escalate to the manager or system administrator if you do not have permission to create accounts or install the required programs.
