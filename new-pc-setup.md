# New PC setup checklist

## Symptom
A PC needs to be prepared for a new employee.

## Possible causes
This is not a fault. It is a routine setup task. A checklist makes sure no step is missed.

## Resolution
1. Turn on the computer and complete the first Windows setup.
2. Open Settings > Windows Update and install all updates. Restart and check again if needed.
3. Open Settings > Privacy & security > Windows Security and check that antivirus protection is on and up to date.
4. Install the programs the employee's department needs.
5. Create the employee's user account. Give a temporary password and force a change at first sign-in.
6. Write the computer's serial number and who it was given to in the asset list.
7. Test that the internet, the printer and email work.

## Verification
All items are ticked and the employee can sign in with their account.

## Escalation
If you do not have permission to create accounts, pass the request to the manager or the system administrator.
