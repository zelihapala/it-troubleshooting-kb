# Slow computer

## Symptom
The computer takes a long time to start, programs freeze, or the fan runs loudly all the time.

## Possible causes
- Too many programs start automatically at startup
- The disk is almost full
- A background program is using a lot of CPU or memory
- The computer has not been restarted for a long time

## Resolution
1. Restart the computer. Machines that stay on for weeks slow down.
2. Press Ctrl + Shift + Esc to open Task Manager. Click the "CPU" and "Memory" column headings to find the program using the most resources.
3. In Task Manager, open "Startup apps". Right-click unnecessary programs and select "Disable".
4. Open Settings > System > Storage and check how much free space is left.
5. Open Settings > Windows Update and install any pending updates.

## Verification
After restarting, the computer starts in a normal time and CPU and disk usage stay low in Task Manager.

## Escalation
If disk usage stays at 100% or the computer is still slow after these steps, it may be a hardware problem. Escalate to the next support level.
