# IT Troubleshooting Knowledge Base

A knowledge base of step-by-step troubleshooting articles for common IT support problems, written in the style used by IT helpdesks. Each article has an ID, a category, the system it applies to, and clear sections so that anyone can follow it.

## How to use this knowledge base
1. Find your problem in the index below.
2. Open the article and follow the Resolution steps in order.
3. Use the Verification section to check that the problem is fixed.
4. If it is not fixed, follow the Escalation section.

## Article structure
Summary, Symptoms, Cause, Resolution, Verification, Prevention, Escalation and Related articles. A blank form is in [article-template.md](article-template.md).
