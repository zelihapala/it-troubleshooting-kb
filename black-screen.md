# Black screen

## Symptom
The computer fan runs and the lights are on, but nothing shows on the screen.

## Possible causes
- The monitor cable is loose
- The monitor is off or the wrong input is selected
- A graphics card or monitor failure

## Resolution
1. Look at the monitor power light. If it is off, check the power cable.
2. If the light is orange, the monitor has no signal. Unplug the monitor cable at both ends (computer and monitor) and plug it back in firmly.
3. Open the monitor's input menu and select the correct input (HDMI, DisplayPort or VGA).
4. Press Windows key + Ctrl + Shift + B at the same time. This restarts the graphics driver.
5. If possible, try another cable or another monitor.
6. If there is still no picture, shut down the computer, unplug the power cable, wait 30 seconds, plug it back in and turn it on.

## Verification
Windows appears on the screen.

## Escalation
If there is no picture even with another cable and monitor, it may be a graphics card or motherboard failure. Escalate to the next support level.
