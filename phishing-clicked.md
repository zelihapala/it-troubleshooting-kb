# Clicked a phishing link or entered a password

## Symptom
The user clicked a link in a suspicious email, entered a password on a fake page, or opened an unknown file.

## Possible causes
A phishing email. The password may have been stolen.

## Resolution
1. Stay calm and thank the user for reporting. Do not blame them; fast reporting is the most important thing.
2. Ask when it happened, what information was entered, and whether a file was downloaded.
3. Reset the user's password immediately.
4. Sign the user out of all active sessions.
5. Check that multi-factor authentication (MFA) is on. Turn it on if it is off.
6. If the user reuses the password on other accounts, ask them to change those too.
7. Report the incident to the security team with all details.

## Verification
The password was changed, sessions were closed, and the security team was informed.

## Escalation
Always inform the security team. If a file was opened, the computer must also be checked.
